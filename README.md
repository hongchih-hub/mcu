## code0915.txt：基本按鈕與多重 LED 狀態切換

實作單一按鈕依序控制多顆 LED 燈的累加點亮與全滅邏輯。

* **控制邏輯**：按下按鈕後，依照以下 4 個狀態往復循環 (1 ➜ 2 ➜ 3 ➜ 4 ➜ 1...)。
* **狀態說明**：
  1. **狀態 1**：僅紅燈亮。
  2. **狀態 2**：紅燈、黃燈一起亮。
  3. **狀態 3**：紅燈、黃燈、綠燈一起亮。
  4. **狀態 4**：全滅。

## code0922.txt：頻率控制與 LED 閃爍切換

實作單一按鈕切換不同 LED 燈的閃爍狀態與頻率 (Duty Cycle 皆為 50%)。

* **控制邏輯**：按下按鈕後，在狀態 1 與狀態 2 之間往復切換。
* **狀態說明**：
  1. **狀態 1**：綠燈閃爍 (頻率 250mHz / D%=50%)。
  2. **狀態 2**：紅燈閃爍 (頻率 1Hz / D%=50%)。

## code0929.txt：進階狀態機 (Mode/Stop/Reset 控制)

結合時間計數與多個按鈕中斷，實作具有預設狀態、計時自動返回以及緊急停止與重置功能的進階狀態機。

* **按鈕定義**：
  * `Mode` 鍵：切換正常運作狀態。
  * `Stop` 鍵：緊急中斷。
  * `Reset` 鍵：系統復位。

* **狀態與邏輯說明**：
  * **預設狀態**：綠燈閃爍 (頻率 1Hz，D%=50%)。
  * **觸發狀態 (按 `Mode` 鍵)**：切換為黃燈閃爍 (頻率 2Hz)。
    * **返回條件**：在黃燈狀態下，若「**超過 5 秒沒有新的觸發**」或是「**再次按下 `Mode` 鍵**」，系統會自動回到預設的綠燈閃爍狀態。

## code1006.txt：電腦指令控制

  * **緊急停止 (按 `Stop` 鍵)**：無論當下處於何種狀態，只要按下 `Stop` 鍵，**一律轉換為紅燈恆亮** (不會全滅，也不會保持原動作)。
  * **系統重置 (按 `Reset` 鍵)**：在紅燈恆亮的鎖死狀態下，唯有按下 `Reset` 鍵，系統才能解除紅燈，並回到預設的綠燈閃爍 (1Hz) 狀態。
